# hello-github

我的第一个 Git 仓库，用来练习最基本的操作。

## 这是什么

一个练习项目。里面没有代码，只有几个文本文件，目的是让你看清楚：
改一个文件 → 提交一次 → 历史里多一条记录，这个循环是怎么运转的。

## 文件说明

- `README.md`：就是你正在看的这个文件。每个仓库都该有一个，说明项目是什么。
- `notes.md`：随便记东西的地方，练习"修改—提交"用。
- `.gitignore`：告诉 Git 哪些文件不用管（比如临时文件、密码）。

## 接下来练什么

1. 改一行 `notes.md`，看看 `git status` 怎么说
2. 提交这次修改，看看 `git log` 怎么说
3. 建一个分支，在上面改，再合并回来
